# 🤝 KeenKeeper — Frontend

The Next.js client application for KeenKeeper, built with React 19, Next.js 15, Tailwind CSS, DaisyUI, and Better Auth client.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **UI & Styling**: React 19, Tailwind CSS v4, DaisyUI v5, React Icons
- **Authentication**: Better Auth Client (`better-auth/react`)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Setup
Create `.env.local` in the `frontend/` directory:
```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
